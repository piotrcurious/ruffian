What makes it rough?

Syncopation — land between the expected pulses.

Anticipation / reply — lean into or answer a kick / snare.

Negative space — leave room for the sample to speak.

Spectral beating — compare measured sample partials with the active MIDI pitches using a critical-band dissonance curve. Near-unison is calm; close, unequal partials grind.

Confidence gating — mostly noisy samples do not receive a fabricated tuning score. MIDI percussion is excluded; MIDI timbre is an estimate because a MIDI file contains note events, not rendered audio.
